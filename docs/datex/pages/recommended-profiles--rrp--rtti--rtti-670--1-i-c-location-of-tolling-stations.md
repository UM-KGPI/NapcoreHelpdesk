## DATEX II packages addressed by the RRP The types of data on infrastructure
### Location of tolling stations
The reference profile defines the minimum required information to identify the location of tollbooths—whether physical or virtual—that collect tolls from passing traffic, either automatically or manually. This location can be expressed using coordinates, a position along a linear element (e.g. a road link), or a mileage reference.
There is no reference profile in DATEX II for locations of tolling stations.
