## Other classes
This page describes all of the other classes in Common::Classes package
### GlobalReference class
The "GlobalReference" class shall provide a versioned reference to an object that may be in another publication from another publisher.
### GroupOfVehiclesInvolved class
The "GroupOfVehiclesInvolved" class may be used for describing a group of vehicles involved having common characteristics ("VehicleCharacteristics", see 2.6) and/or status.
### HazardousMaterials class
The “HazardousMaterials” class may be used to allow a supplier to identify the actual details of any hazardous material or dangerous goods that the vehicle is carrying or at least is thought to be carrying.
### HeaderInformation class
The “HeaderInformation” class shall specify management information relating to the data contained within a publication.
### Source class
Language independent textual code or identifier for the organisation or the equipment which has produced the information.
### UrlLink class
The “UrlLink" class may provide details of a Uniform Resource Locator (URL) address pointing to a resource available on the Internet from where further relevant information may be obtained.
