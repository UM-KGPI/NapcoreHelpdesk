## DATEX II packages addressed by the RRP The types of data on infrastructure
### Road network links and their physical attributes
#### Geometry
The reference profile for Geometry defines the minimum required information to represent the geometry of road network links in a centerline or more detailed manner. These links connect two positions and together form a continuous, unbranched path.
Since road links are inherently curvilinear, their geometry—following the INSPIRE data specifications—can be represented using the GM_Curve object from the GM_Object hierarchy as defined in ISO 19107.
Alternatively, geometry may also be expressed using a piecewise linear representation.
For more information, refer to the INSPIRE Technical Guidelines for Transport Networks.
