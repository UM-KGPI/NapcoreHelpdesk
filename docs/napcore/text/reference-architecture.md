#### NAP Reference Architecture: A Common Blueprint for Harmonised and Interoperable National Access Points
#### Driving EU-wide mobility data interoperability through a shared architectural foundation.
The NAP Reference Architecture (NRA), developed under the NAPCORE project, provides a harmonised framework for designing, aligning, and evaluating National Access Points (NAPs) across Europe. It defines the minimum functional, organisational, and technical requirements for two key NAP types — Metadata Directory and Data Platform — and supports Member States in building interoperable, future-proof mobility data ecosystems. The NRA is based on the FRAME methodology and developed using Enterprise Architect tooling. It is continuously maintained and enriched through collaboration across NAPCORE working groups and is available free of charge for public use.
FRAME Methodology in NAPCORE
The NRA is built on the FRAME (FRamework Architecture Made for Europe) methodology, which offers a modular, standards-based approach to designing Intelligent Transport Systems (ITS). In NAPCORE, FRAME is created using the Enterprise Architect modelling tool — enabling the development of structured architectural views that reflect real-world NAP functions and needs. These views include motivational, functional, organisational, physical, communication, and security aspects, forming a robust blueprint for Member States to harmonise their systems. The combination of FRAME principles and Enterprise Architect tooling ensures a maintainable, scalable, and reusable foundation for future mobility data infrastructure.
Guidelines, Typology & Interoperability
To support practical implementation, NAPCORE has developed a NAP typology, comprehensive set of guidelines that extend the NRA into real-world use. These guidelines provide a methodology for describing legal documents, technical standards, and interfaces, and for linking them through clearly defined requirements. The NRA also support the integration of the NAP Level of Service KPI Framework (NLKF), enabling Member States to assess their NAPs and identify functional or structural gaps. By translating regulatory texts into architectural elements and connecting them to system requirements, the guidelines ensure that the NRA is not just a theoretical model, but a practical tool for harmonisation, benchmarking, and continuous improvement.
Website, GitHub & Maintenance
The NRA is openly accessible via the Reference Architecture Website, which offers a browsable model of the architecture. The full model, FRAME toolbox, and versioned releases are available on GitHub, including importable EA/XMI files for use in Enterprise Architect and maintenance guidelines ensure transparency and long-term usability. To ensure transparency and long-term usability, the GitHub repository also supports community-driven maintenance: users can submit feedback, raise issues, or suggest improvements directly through the issue tracker. This open process allows stakeholders to contribute to the evolution of the NRA and ensures that updates reflect real-world needs. Supporting materials such as M2.11 deliverable and maintenance guidelines provide additional context and governance for ongoing development.
