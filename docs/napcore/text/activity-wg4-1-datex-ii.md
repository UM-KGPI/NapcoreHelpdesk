M4.1.500 Change requests on methodology
M4.1.600 Cybersecurity Reference Architecture Model and Building Block Repository
The actors, data, and the technical aspects involved in a DATEX II exchange have similarities in other sectors. A Datex II project typically involves the exchange of road conditions and traffic-related information as well as information about traffic management decision to be agreed and cooperatively acted among a number of stakeholders, which may have different cybersecurity posture who commit to solve interoperability problems using a standardized information sharing.
The Cybersecurity working group identified similarities in additional three sectors: healthcare, electronic delivery, and International Data Space Association (IDSA). This document is composed as follows: the first sections will analyse the Reference Architecture for security for the three sectors mentioned above, and in the last section, we will perform a discussion on how DATEX II can learn from the experiences, and we conclude.
