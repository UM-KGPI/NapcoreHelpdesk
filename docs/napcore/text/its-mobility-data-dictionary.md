#### ITS Mobility Data dictionary
#### First version of the ITS Mobility Data Dictionary
NAPCORE is proud to announce the release of the first version of the ITS Mobility Data Dictionary that outlines the definitions for each data category mentioned in the EU Delegated Regulations (No. 885/2013, 886/2013, 2015/962, 2022/670) supplementing the ITS Directive (2010/40/EU).
What’s inside?
For each data category, a clear definition is provided along with a brief description of the information that needs to be exchanged within its context.
Why this matters?
Having clear and standardized definitions for all these data categories is essential for enhancing interoperability and consistency in order to achieve harmonization across European NAPs.
Repository
In addition, NAPCORE has established a specific repository on GitHub where all documents are uploaded. Change management rules are in place, ensuring that respective editing groups make any necessary changes based on the received feedback from stakeholder communities.
Link to the NAPCORE repository: https://github.com/NAPCORE/its-data-dictionary
Upcoming updates
Looking ahead, we plan to extend our efforts to include definitions for MMTIS DR (2017/1926) in future versions. Stay tuned for further updates!
